# GOLDEN EVENTS MANAGEMENT

Mobile-friendly event decoration website for Golden Events Management, Gondia.

## Included
- Professional wedding/event-decoration landing page
- Services, gallery, about and contact sections
- WhatsApp + call buttons
- Admin page at /admin.html
- Photo/post demo manager

## IMPORTANT ABOUT PHOTO UPLOAD
The included admin page is a front-end demo: uploaded images are stored in the browser's localStorage. They do NOT automatically become visible on other phones/devices.

For a real online system where you can login from any phone and upload photos/posts to the live website, connect a backend such as Firebase or Supabase. The UI is already prepared for that next step.

## Quick Netlify publish
1. Open Netlify and log in.
2. Use "Add new site" -> "Deploy manually".
3. Upload this folder/ZIP after extracting it.
4. Open the generated site URL.
5. Replace the placeholder gallery images with your own photos through the real backend setup.
